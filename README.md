# DHOOM 🚀
> *"Keep moving. Keep firing. Don't look back."*

**Dhoom** is a high-octane, cinematic rail-shooter built in Unity. Set in the treacherous Volcanic Sector, players must pilot their ship through a dark, ash-choked nebula, dodging obstacles and surviving waves of enemy fighters to secure the mothership.

## 🌌 Visuals & Aesthetic
The game features a heavy, contrast-driven sci-fi aesthetic:
* **The Environment:** Dark, smoky nebulas featuring snow-capped sub-glacial volcanoes. 
* **Neon Combat:** High-contrast weapon systems featuring Plasma Yellow (Player) and Neon Pink (Ally) lasers.
* **Cinematic Presentation:** Real-time Timeline animations, anamorphic bloom, and custom Canvas Group UI fading for a seamless, movie-like experience between gameplay and cutscenes.

## 🔥 Key Features
* **Fast-Paced Rail Combat:** Navigate high-speed obstacle courses while managing incoming enemy fire.
* **Dynamic Wingman System:** Coordinated tactical strikes with your ally.
* **Epic Boss Encounters:** Multi-stage boss fights featuring custom explosion VFX and intense screen-shake impacts.
* **Immersive Audio:** Backed by a heavy dark synthwave soundtrack and a custom "Voice of God" cinematic narrator.

## 🎮 Controls
* **W / A / S / D** - Steer Ship 
* **Left Mouse Click** - Fire Primary Lasers

## 🛠️ Built With
* **Engine:** Unity 3D
* **Language:** C#
* **Systems Used:** Unity Timeline (Cinematics), Particle System (VFX), Canvas Groups (Dynamic UI), Cinemachine (Camera manipulation).
* **Audio Generation:** Google AI Studio

## 💻 Installation (For Developers)
1. Clone the repository: `git clone https://github.com/Kaylin98/Dhoom.git`
2. Open Unity Hub and click **Add Project**.
3. Select the cloned `Dhoom` folder.
4. Open the `MainLevel` scene in the `Scenes` folder.
5. Hit **Play** and try not to get blown up.
